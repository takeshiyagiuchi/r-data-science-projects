# R Data Science Projects

This repository contains a collection of data science projects implemented in R, focusing on **data wrangling, visualization, and analytical reasoning**.

The projects emphasize working with real-world data, including messy text inputs and geospatial datasets, and demonstrate reproducible analysis using Quarto.

---

## Projects

### 📊 Salary Analysis (`ask-a-manager`)
Analysis of job salary data with a focus on data cleaning, transformation, and visualization.

- Cleaned messy free-text survey data using regular expressions  
- Explored relationships between salary and factors such as industry, experience, and education  
- Created visualizations using `ggplot2` to support data-driven insights  

👉 Focus: data wrangling, exploratory data analysis, visualization  

---

### 🔥 Wildfire Analysis in British Columbia (`wildfire-bc-canada`)
Geospatial analysis of wildfire activity in British Columbia from 2012 to 2024.

- Processed `.kml/.kmz` geospatial data using `sf`  
- Parsed hierarchical data structures using `xml2` and `rvest`  
- Performed web scraping for data validation  
- Created spatial and temporal visualizations using `tmap` and `leaflet`  

👉 Focus: geospatial analysis, web scraping, data validation, mapping  

---

## Skills Demonstrated

- **R programming** (`tidyverse`, `ggplot2`, `sf`)  
- **Data wrangling and cleaning**
